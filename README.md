# Шаблоны отчётов на Typst

Отчёты кафедры ВТиЭ АлтГУ: практика и лабораторная работа.
Оба варианта используют общее оформление и редактируются в одной ветке.

## Сборка

Нужны Typst и шрифты Times New Roman и DejaVu Sans Mono.
Команды выполняются из корня репозитория. Make не требуется.

Отчёт по практике с рефератом (результат — `main.pdf`):

```sh
typst compile main.typ
```

Лабораторная работа без реферата (результат — `lab.pdf`):

```sh
typst compile --input report=lab main.typ lab.pdf
```

Вариант по умолчанию задаётся в корневом `main.typ`: замените
`default: "practice"` на `default: "lab"`, чтобы обычная команда
`typst compile main.typ` собирала лабораторную работу.
Параметр `--input report=...` имеет приоритет над этим значением.

Автоматическая пересборка лабораторной работы:

```sh
typst watch --input report=lab main.typ lab.pdf
```

Для явного выбора практики используйте `--input report=practice`.
При компиляции файла внутри `reports/` вместо корневого файла нужно указать
корень проекта: `typst compile --root . reports/lab/main.typ lab.pdf`.

## Структура

```text
main.typ                         # выбор варианта отчёта
template/
  lib.typ                        # общие стили, титульный лист, реферат
  gost-r-7-0-5-2008-numeric.csl    # общий стиль библиографии
reports/
  practice/                      # отчёт по практике
    main.typ                     # реквизиты и состав отчёта
    chapters/chapter-N.typ       # главы
    references.yml              # источники
    images/                     # изображения
    src/                        # примеры кода для листингов
  lab/                           # лабораторная работа, та же структура
reference/                       # эталон LaTeX, сабмодуль csae-report
Docs/                            # локальная методичка, вне Git
AGENTS.md                        # правила работы с шаблоном
```

## Редактирование

- Реквизиты отчёта задаются в словаре `meta` файла `reports/<вариант>/main.typ`.
- Главы подключаются в том же файле из `chapters/`.
- Из главы изображение подключается через `../images/имя`, исходный код —
  через `../src/имя`. Пути считаются от файла, в котором вызвана функция.
- Источники каждого отчёта хранятся в его `references.yml`.
- Оформление обоих отчётов меняется в `template/lib.typ`.
- Реферат подключён только в практике. Его текст и счётчики задаются в `meta`.

Общее оформление перенесено из коммита `f718218` ветки `lab`: зазор между
строками и абзацами `10pt`, нумерованные списки `1.`, `1.1.`, заголовки глав
без дополнительного отступа от верхнего поля. Различия состава отчётов сохранены.
Для выбора вида отчёта переключать Git-ветку больше не требуется.

## Проверка оформления

После изменения общих стилей собираются оба варианта. Для просмотра страниц:
создайте каталог `build/`, затем выполните команды:

```sh
typst compile --format png main.typ 'build/practice-{p}.png'
typst compile --input report=lab --format png main.typ 'build/lab-{p}.png'
```

PDF и каталог `build/` исключены из Git.
